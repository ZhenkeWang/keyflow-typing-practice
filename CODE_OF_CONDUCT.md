# Code of Conduct

## Our standard

We want KeyFlow to be a welcoming, constructive project. Participants should:

- Communicate with respect and assume good intent.
- Give actionable feedback about the work, not the person.
- Welcome contributors of different backgrounds and experience levels.
- Respect privacy, attribution, licensing, and security boundaries.
- Accept maintainer decisions made to protect users and project quality.

Harassment, discrimination, threats, deliberate disruption, publishing private
information, and other abusive behavior are not acceptable.

## Scope

This policy applies to repository discussions, issues, pull requests, reviews,
and public spaces where someone represents the project.

## Enforcement

Report conduct concerns privately through the repository maintainer's GitHub
profile. Maintainers may edit or remove content, close discussions, restrict
participation, or ban contributors when necessary.

Reports will be handled as confidentially as reasonably possible. Retaliation
against someone who reports a concern is prohibited.
