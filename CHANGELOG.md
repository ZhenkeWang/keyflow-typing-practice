# Changelog

All notable changes to KeyFlow are documented here.

## [1.0.0] - 2026-07-31

### Added

- Low-latency typing engine with real-time speed and accuracy metrics
- Multiple speed, accuracy, weak-key, rhythm, coding, and number modes
- Virtual keyboard, character feedback, immersive mode, and result analysis
- Progress dashboard, XP, levels, missions, streaks, skills, and achievements
- Personal coach analysis, training recommendations, and growth prediction
- Light, dark, automatic, reduced-motion, and high-contrast experiences
- Optional Supabase authentication and synchronization
- Responsive PWA and Cloudflare-compatible production packaging

### Open source

- Added MIT licensing for original KeyFlow code
- Added separate React Bits Aurora notice and upstream license
- Added contributor, security, privacy, and community documentation
- Added continuous integration and dependency update configuration
